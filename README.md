# Ki Communities

A single-page website for Ki Communities, built as a self-contained `index.html`. Its styles, fonts and base64-encoded images are all in that one file.

## View it locally

Open `index.html` in any browser. There's no build step.

## Publish it with GitHub Pages

1. Go to **Settings → Pages** in this repository.
2. Under **Source**, pick **Deploy from a branch**, then choose `main` and `/ (root)`.
3. Save. After a minute the site will be live at the URL GitHub shows there.
